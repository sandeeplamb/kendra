# Runbooks

One page per failure you can hit while using Kendra.

| Runbook | When |
|---|---|
| [Cluster login failed or expired](cluster-login-failed.md) | A cluster card or list shows "Login for this cluster failed or expired" |
| [No window opens](no-window-opens.md) | `knd` prints an address but nothing appears |
| [macOS blocks the app or package](macos-blocks-the-app.md) | "cannot be opened because the developer cannot be verified" |
